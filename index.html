1 · Row Reduction, Span, Linear Independence (Ch. 1)

1.1–1.2 · Systems of Linear Equations

Augmented matrix → RREF → Read off solution
• Pivot column = basic variable · Non-pivot column = free variable
• Consistent iff no pivot in last column of augmented matrix
• Unique solution: no free variables · Infinitely many: ≥1 free variable
Parametric vector form (exact exam style):
After row-reducing, express basic variables in terms of free variables, then write: 
x = p + s·v₁ + t·v₂ + ...
where p is a particular solution, v₁, v₂,… span the null space.

1.3–1.5 · Vector Equations & Matrix Equations

The four equivalent statements (all mean the same thing for an m×n matrix A):
① Ax = b is consistent for every b in ℝᵐ
② The columns of A span ℝᵐ
③ A has a pivot in every row
④ The column space Col(A) = ℝᵐ
▶ Watch 3Blue1Brown — Linear Combinations, Span & Basis Vectors  ·  3Blue1Brown — Essence of Linear Algebra (Intro)

1.7 · Linear Independence

Vectors {v₁,…,vₚ} are linearly dependent iff c₁v₁+…+cₚvₚ = 0 has a non-trivial solution.

Quick facts:
• Any set containing the zero vector is linearly dependent.
• More vectors than entries (p > m)? Always linearly dependent.
• Two vectors are linearly dependent iff one is a scalar multiple of the other.
⚠ A set of 5 vectors in ℝ⁴ is always linearly dependent. A set of 4 vectors in ℝ⁴ is not necessarily a basis — they might still be dependent.

1.8–1.9 · Linear Transformations

Standard matrix of T: A = [T(e₁) | T(e₂) | … | T(eₙ)]

One-to-one ↔ every column of A has a pivot ↔ Null(A) = {0}
Onto ↔ every row of A has a pivot ↔ Col(A) = ℝᵐ

Geometric transformations in ℝ²:
TransformationMatrix
Rotation by θ (CCW)[cos θ, −sin θ; sin θ, cos θ]
Reflection about x₁-axis (x₂=0)[1, 0; 0, −1]
Reflection about x₂-axis (x₁=0)[−1, 0; 0, 1]
Reflection about x₁=x₂[0, 1; 1, 0]
Horizontal shear[1, k; 0, 1]
Composition: "First T then S" → matrix = A_S · A_T (right-to-left!)

Practice final style: Rotation by 5π/3 CCW then reflect about x₂=0:
Step 1: R = [cos(5π/3), −sin(5π/3); sin(5π/3), cos(5π/3)] = [½, √3/2; −√3/2, ½]
Step 2: Reflect about x₂=0 (x-axis): F = [1,0;0,−1]
Step 3: A = F·R = [½, √3/2; √3/2, −½]
⚠ To show a map is NOT a linear transformation, check T(0) ≠ 0 — the easiest method. A linear transformation must always send 0 → 0.

2 · Matrix Algebra, Inverse, Subspaces, Rank (Ch. 2)

2.1–2.3 · Matrix Operations & Inverse

Finding A⁻¹ by row reduction: Set up [A | I] and reduce to [I | A⁻¹].

Invertible Matrix Theorem (IMT) — all equivalent for n×n matrix A:
• A is invertible  ·  det(A) ≠ 0  ·  Null(A) = {0}
• Columns are linearly independent  ·  Columns span ℝⁿ
• A has n pivot positions  ·  rank(A) = n
• 0 is not an eigenvalue of A
Using a known inverse to find related inverses (Practice Final Q4):
If A⁻¹ is known, note B = 3A → B⁻¹ = (1/3)A⁻¹
If C = −A⁻¹ → C⁻¹ = −A   (use (AB)⁻¹ = B⁻¹A⁻¹ repeatedly)
▶ Watch 3Blue1Brown — Inverse Matrices, Column Space & Null Space  ·  Khan Academy — Inverting a 3×3 Matrix

2.8–2.9 · Subspaces, Col(A), Null(A), Rank

Col(A): span of columns of A. Lives in ℝᵐ for an m×n matrix.
Nul(A): solutions to Ax=0. Lives in ℝⁿ.
Row(A): span of rows of A. Lives in ℝⁿ.

Rank-Nullity Theorem: rank(A) + nullity(A) = n (# columns)

rank(A) = rank(Aᵀ) always.

To verify v ∈ Col(A): row reduce [A | v] — consistent means v ∈ Col(A).
Coordinates in Col(A): if Col(A) basis = {u₁, u₂}, solve c₁u₁+c₂u₂ = v.
⚠ Col(A) of a 5×3 matrix is a subspace of ℝ⁵, not ℝ³. The columns have 5 entries.

How to find a basis for Col(A) and Nul(A)

Basis for Col(A): Row-reduce A. The pivot columns of the original matrix A form a basis for Col(A).

Basis for Nul(A): Solve Ax = 0 (parametric vector form). The vectors multiplied by free variables are the basis vectors.

Checking if S is a Subspace

A subset S of ℝⁿ is a subspace iff:
① 0 ∈ S
② Closed under addition: u,v ∈ S → u+v ∈ S
③ Closed under scalar multiplication: u ∈ S, c∈ℝ → cu ∈ S

Fastest failure check: Does it contain 0? If not, done — not a subspace.
Practice Final Q6 — S = {[x,y] : y = x²} ⊆ ℝ²:
[1,1] ∈ S, [2,4] ∈ S. Sum = [3,5]: is 5=3²? No → NOT a subspace.

S = {[a,b,c] : a+b=2c}:
Contains 0? Yes. Write a=2c−b → [a,b,c] = b[−1,1,0] + c[2,0,1].
Subspace, basis = {[−1,1,0], [2,0,1]}.

3 · Determinants & Cramer's Rule (Ch. 3)

3.1–3.2 · Computing Determinants

Cofactor expansion along row 1:
det(A) = a₁₁C₁₁ + a₁₂C₁₂ + a₁₃C₁₃
where C₁ⱼ = (−1)^(1+j) · det(minor)

Row operation effects on det:
• Swap two rows → multiply det by −1
• Multiply a row by k → multiply det by k
• Add multiple of one row to another → det unchanged

Triangle matrix: det = product of diagonal entries

det(kA) = kⁿ det(A) for n×n matrix   det(AB) = det(A)·det(B)
det(A⁻¹) = 1/det(A)   det(Aᵀ) = det(A)
Practice Final Q2 — Parametric determinant:
A = [k, 0, 0; 0, 3, k; 0, k, 12]
Expand along row 1: det(A) = k · det([3,k;k,12]) = k(36−k²) = k(6−k)(6+k)
A is invertible ↔ k ≠ 0, 6, −6
⚠ det(2A) = 2ⁿ det(A). For a 3×3 matrix, det(2A) = 8 det(A), NOT 2 det(A). Classic trap.

3.3 · Cramer's Rule

For Ax = b where A is n×n invertible:
xᵢ = det(Aᵢ(b)) / det(A)
where Aᵢ(b) = A with the i-th column replaced by b.
Practice Final Q5: Show x₂ = 0.
Replace col 2 of A with b → that determinant = 0 → x₂ = 0/det(A) = 0.
Without Cramer's Rule: row-reduce [A|b].

4 · Eigenvalues, Eigenvectors, Diagonalization (Ch. 5)

5.1 · Eigenvalues & Eigenvectors

λ is an eigenvalue of A if Av = λv for some nonzero v.

Step 1: Solve det(A − λI) = 0 to find eigenvalues.
Step 2: For each λ, find Eλ = Nul(A − λI) by solving (A − λI)x = 0.

Algebraic multiplicity = power of (λ−λ₀) in characteristic polynomial
Geometric multiplicity = dim(Eλ)   Always: geom. mult ≤ alg. mult
Properties:
• det(A) = product of eigenvalues  ·  tr(A) = sum of eigenvalues
• A and Aᵀ have the same eigenvalues (not necessarily same eigenvectors)
• Similar matrices have the same eigenvalues
• λ eigenvalue of A → λⁿ eigenvalue of Aⁿ
⚠ The zero vector is never an eigenvector. The definition requires v ≠ 0.

5.2 · The Characteristic Equation

2×2 shortcut: p(λ) = λ² − tr(A)·λ + det(A)

Triangular matrices: eigenvalues = diagonal entries (read directly).

5.3 · Diagonalization

A = PDP⁻¹ where D is diagonal.

A is diagonalizable iff for every eigenvalue, geometric mult = algebraic mult.
Sufficient (not necessary): n distinct eigenvalues → diagonalizable

Build P & D:
P = eigenvectors as columns  ·  D = corresponding eigenvalues on diagonal (same order)
Computing Aⁿ: If A = PDP⁻¹ then Aⁿ = PDⁿP⁻¹   (raise each diagonal entry to n)

Practice Final Q7e — Compute A¹⁰, eigenvalues 4 (mult 2) and 2 (mult 1):
D¹⁰ = diag(4¹⁰, 4¹⁰, 2¹⁰)  →  A¹⁰ = P · D¹⁰ · P⁻¹
⚠ Repeated eigenvalues don't automatically mean non-diagonalizable — check if geom. mult = alg. mult for each one.

5.5 · Complex Eigenvalues

Real matrix with complex eigenvalue λ = a+bi:
• Conjugate λ̄ = a−bi is also an eigenvalue (automatic)
• Eigenvectors come in conjugate pairs

2×2: p(λ) = λ² − tr(A)·λ + det(A) → solve with quadratic formula
Practice Final Q8: A = [3,4;−4,3]
p(λ) = λ² − 6λ + 25  →  λ = 3 ± 4i
For λ = 3+4i: row-reduce [A−(3+4i)I] → eigenvector [1; i]
Conjugate: [1; −i] (automatic)
P = [1,1; i,−i], D = diag(3+4i, 3−4i)

Non-diagonalizable matrices

Practice Final Q9: A = [2,1,0;0,2,1;0,0,2]
p(λ) = (2−λ)³ → λ=2, alg. mult. 3
Row-reduce (A−2I): only one free variable → dim(E₂) = 1 < 3 → NOT diagonalizable

Similarity

B = PAP⁻¹ (similar) → same: det, trace, eigenvalues, rank, char. polynomial

To prove similar: Show both are diagonalizable with same eigenvalues → both similar to same D.
To disprove similar: Find tr(A) ≠ tr(B) or det(A) ≠ det(B) — instant kill.
Trap: Same eigenvalues ≠ similar. Counterexample: [1,1;0,1] vs I both have λ=1 (mult 2) but [1,1;0,1] is not diagonalizable while I is.

5 · Eigenvectors & Linear Transformations (5.4)

The B-matrix of a Linear Transformation

Let B = {b₁, …, bₙ} be a basis for ℝⁿ and T: ℝⁿ → ℝⁿ a linear transformation with standard matrix A.

The B-matrix of T (matrix of T relative to basis B) is:
[T]_B = P⁻¹AP
where P = [b₁ | b₂ | … | bₙ] (the change-of-basis matrix).

Key idea: [T]_B is similar to A. They represent the same transformation, just in different coordinate systems.

Why this matters for diagonalization

If A is diagonalizable with eigenvectors p₁,…,pₙ and eigenvalues λ₁,…,λₙ:
Let B = {p₁,…,pₙ} (eigenvector basis), P = [p₁|…|pₙ].

Then: [T]_B = P⁻¹AP = D (diagonal!)

This is exactly diagonalization — the B-matrix is diagonal when B is the eigenvector basis.
Example: A = [3,1;0,3], eigenvector basis B = {[1,0],[0,1]} (standard).
P = I, so [T]_B = I⁻¹AI = A. Nothing changes with the standard basis.

Now let B be the eigenvector basis of a diagonalizable A:
If A = PDP⁻¹, then [T]_B = P⁻¹AP = D — you get the diagonal eigenvalue matrix.

The punchline: Every diagonalizable matrix A is just a scaling transformation when viewed in the right basis (its eigenvector basis).
Key facts for T/F:
• Similar matrices A and B represent the same linear transformation in different bases.
• If A = PDP⁻¹, the columns of P are the B-basis vectors (eigenvectors) and [T]_B = D.
• [T]_B is diagonal iff B is a basis of eigenvectors of A.

7 · Exam Tactics

True/False (~15–20 questions): Always give a reason. For FALSE, give a specific counterexample — not "not necessarily."

Row reduction: Write each row operation (R₂ → R₂ − 2R₁). Don't skip steps.

Determinant: Expand along the row/column with the most zeros.

Eigenvalue workflow:
① det(A−λI)=0 → eigenvalues   ② Row-reduce (A−λI) → eigenvectors
③ Check geom=alg mult → diagonalizable?   ④ Build P and D

Subspaces: Check 0∈S first. Then write parametrically → read off basis.

Time (110 min): True/False ~30 min · Computation ~70 min · Review ~10 min
Top mistakes:
① det(2A) ≠ 2det(A) — it's 2ⁿdet(A)
② Col(A) lives in ℝᵐ, not ℝⁿ
③ Same eigenvalues ≠ similar
④ Every column has pivot → one-to-one (NOT onto). Every row → onto
⑤ Eigenvector requires v ≠ 0
⑥ Composition order: "first T then S" = A_S · A_T (right to left)
⑦ Aⁿ = PDⁿP⁻¹, don't forget to compute P⁻¹
